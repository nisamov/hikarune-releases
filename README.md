## Información de descargas

| Nota | Detalle |
|---|---|
| Enlaces de descarga | Los enlaces de los instaladores usan `releases/latest/download/`. GitHub los redirige al archivo con ese nombre en la última release publicada. |
| Versiones anteriores | Para descargar una versión concreta, entra en [el historial de releases](https://github.com/nisamov/hikarune-releases/releases) y selecciona la versión correspondiente. |
| Código fuente | Los archivos ZIP y TAR.GZ son generados por GitHub para cada etiqueta; por eso se accede a ellos desde la página de la release y no mediante un enlace fijo a una versión. |
| SHA-256 | Comprueba siempre el digest correspondiente a la misma release y al mismo archivo que has descargado. No reutilices hashes de versiones anteriores. |
